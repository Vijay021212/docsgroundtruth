# DocsGroundTruth

A production-grade Retrieval-Augmented Generation (RAG) system for healthcare documents.

## Overview

DocsGroundTruth demonstrates how to build a scalable RAG system that retrieves relevant information from healthcare documents and generates accurate, cited answers using local and open-source models.

## Features

- **Local LLMs**: Uses Ollama to run models locally (Qwen3 4B for generation, Nomic Embed Text for embeddings)
- **Semantic Search**: Vector embeddings + BM25 hybrid search for robust retrieval
- **Healthcare Focus**: Designed and evaluated on healthcare policy documents
- **Production Ready**: Includes API, evaluation harness, and automated tests
- **Pluggable Models**: Easy to swap Ollama for other model APIs
